# 国内版：放到阿里云函数计算（给 iPhone、没有电脑的用户）

iPhone 不能在手机上跑模型。没有电脑的话，可以把 Pocket Voice 放到**你自己的**阿里云函数计算（FC）上：有人说话才算钱，新用户有免费试用额度。

> 这份是草稿，按 2026 年 11 月的阿里云文档写的，还没有大陆账号从头走过一遍。遇到哪一步和画面对不上，截图问作者。

## 你需要

- 一个阿里云账号，**完成实名认证**（大陆手机号＋身份证）
- 一个 Gitee（码云）账号，用来放代码
- 手机浏览器就够了，不用电脑

## 一、把代码搬到 Gitee

1. 登录 Gitee，右上角 **＋ → 从 GitHub / GitLab 导入仓库**。
2. 仓库地址填：`https://github.com/yuhannnhong/lumeet-pocket-voice-0.1.2`
3. 仓库名随意，设成**私有**也可以。点「导入」。

## 二、开通函数计算的免费试用

1. 阿里云官网搜「免费试用」，进免费试用中心，找到 **函数计算 FC**，领取新用户试用额度。
2. 额度按月给、一共三个月，超出部分按量计费。具体额度以领取页面写的为准。
3. 建议顺手在「费用中心」设一个**预算提醒**（例如 10 元），超了会通知你。

## 三、用容器镜像服务把镜像建出来

1. 搜「容器镜像服务 ACR」，开通**个人版**（目前免费）。第一次进去会让你设一个 Registry 登录密码，随便设、记下来。
2. 地域选离你近的（例如华东1 杭州），**之后函数计算也选同一个地域**。
3. 先建一个**命名空间**（名字随意，例如 `mine`）。
4. 建**镜像仓库**：名字 `pocket-voice`，类型选**私有**，代码源选 **Gitee**，绑定你的 Gitee 账号，选第一步导入的仓库。
5. 进这个镜像仓库 → **构建** → 添加构建规则：
   - 类型：Branch，分支：`main`
   - **Dockerfile 目录：`/cn/`**
   - **Dockerfile 文件名：`Dockerfile`**
   - 镜像版本（Tag）：`latest`
6. 点「立即构建」。第一次大约 10～20 分钟（要下载约 730 MB 的模型）。日志最后显示成功就好。

> 如果构建日志卡在下载模型或基础镜像：构建规则里如果有「使用海外机器构建」，打开它再构建一次。

## 四、建函数

1. 进函数计算 FC（3.0）→ **创建函数** → 选 **Web 函数**（或「自定义镜像」）。
2. 运行环境选**自定义镜像**，镜像选上一步的 `pocket-voice:latest`。
3. **监听端口填 `7860`**。
4. 规格：**2 vCPU、4 GB 内存**起步（太小会跑不动或很慢）。执行超时设 **120 秒**。
5. 环境变量加三个：
   | 名字 | 值 |
   |---|---|
   | `POCKET_VOICE_TOKEN` | 自己想一串长一点的密码（Lumeet 要填同一串） |
   | `CPU_THREADS` | `2` |
   | `VOICES_DIR` | `/tmp/voices` |
6. 触发器：HTTP 触发器，**认证方式选「无需认证」**（服务器自己会检查上面那串密码，没带密码的请求一律拒绝）。
7. 创建完成后，在触发器页面复制**公网访问地址**。

## 五、测试

1. 手机浏览器打开 `公网访问地址/health`。第一次要等 30 秒左右（在加载模型）。
2. 浏览器可能会把结果当成文件下载，这是阿里云默认域名的规定，不影响使用。打开下载的文件，看到 `"loaded": true` 就成功了。

## 六、填进 Lumeet

设置 → API 统一管理 → 角色 → 声音来源选「我的服务器（Pocket Voice）」：

- 服务器网址：第四步复制的公网访问地址（`https://` 开头，结尾不要 `/`）
- 服务器密码：`POCKET_VOICE_TOKEN` 那一串
- 再上传一次声音样本（5～20 秒，干净、没有背景音乐）

## 注意

- **一段时间没人用，实例会被回收**，下一句要多等半分钟左右重新加载模型。正常聊天时速度和电脑版差不多。
- 阿里云说默认域名**仅供测试**，自己一个人用没问题；要给别人用需要绑定备案过的域名。
- 函数是你自己账号里的，声音样本和模型都只在你的账号里，作者看不到。
- 不用了记得把函数删掉，免得试用期过后被计费。
